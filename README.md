# Her Stronger Self — static home fitness app

A single-file static website for a simple 12-week home fitness routine.

## Run it
Open `index.html` in any modern browser.

## Put it online for free
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Repository Settings → Pages → deploy from the main branch.
4. Share the resulting URL with your wife.

### Netlify
Drag the folder containing `index.html` into Netlify's deploy area.

No database, server, build step, login, or installation is required.

## Features
- Monday / Tuesday / Thursday / Friday / Saturday plan
- Individual YouTube exercise links
- Exercise completion checkmarks
- Progress bar
- 60-second rest timer
- Mobile-friendly layout
- Progress saved locally in the browser

The YouTube links are form/tutorial links or YouTube searches. The app does not claim that any single exercise causes weight loss; weight loss comes primarily from sustained energy deficit plus regular activity and strength training.
